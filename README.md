# SEARCH FIT

기사를 SEO · GEO · AEO · NEO 네 축으로 진단하고, 최적화 초안을 만들어 원문과 대조하는 콘솔.

- **SEO** 구글 등 일반 검색엔진
- **GEO** 생성형 엔진 인용 최적화
- **AEO** 답변 엔진(스니펫·FAQ)
- **NEO** 네이버 검색 최적화

## 쓰는 법

기사 본문을 붙여넣거나 URL을 넣고 **진단 · 재작성 실행**. 왼쪽 `진단`에서 항목별 미달 사유를,
오른쪽 `체크`에서 원문 대비 어디를 바꿨는지 봅니다. `복사`는 표기를 걷어낸 완성 기사만 내보냅니다.

주소 뒤에 `?test=1`을 붙이면 내장 셀프체크가 콘솔에서 돕니다.

## AI 전면 재작성

규칙 기반 재작성은 구조(제목·요약·소제목·FAQ)만 바꾸고 본문 문장은 원문 그대로 둡니다.
문장까지 다시 쓰려면 내려받아 로컬 `config.js`에 Anthropic API 키를 넣으세요.
**공개 저장소에는 키를 올리지 마세요.**
